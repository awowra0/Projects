# Arcanoid
Break bricks and get more points than computer.
Each brick may contain bonus that may help or not.
Game ends after cleaning third board.
# Requirements
Java
#Controls
Mouse movement - paddle movement.
Left Mouse Button - release ball.
P - pause
Q - restart
H - second player toggle
AD, Arrows - second player's paddle movement
Space - release ball for second player
# How to run
Write in terminal "javac Program.java" and "java Program" in game directory.
